# Registro de decisões arquiteturais (ADR)

| ADR | Título | Status |
|---|---|---|
| ADR-001 | Decisão de banco de dados | Proposto |
| ADR-002 | Arquitetura de implantação híbrida Cloud/Private | Proposto |

**Regra:** uma ADR só muda para *Aceito* por aprovação explícita do responsável pelo projeto, registrada no próprio arquivo (data e aprovador). Até lá, nada nela é decisão definitiva e nenhum código deve depender dela de forma irreversível.
